killer7-vr: a VR mod for Killer7 (PC, Steam) through SteamVR
https://github.com/idio-sync/k7-vr

Install
  Extract the zip into the game folder, the one with Killer7Win.exe (in Steam: right-click
  Killer7, Manage, Browse local files). XINPUT1_3.dll and openvr_api.dll go next to
  Killer7Win.exe; keep their names exactly as they are.

Play
  Start the game with the headset connected: VR turns on by itself (SteamVR starts if it isn't
  running). Without a headset the game plays flat. Hold Shift while the game starts to play flat.
  Hold both stick clicks for a second to recentre the view.

Settings and log
  k7vr\k7vr.ini (created on the first start, every setting commented out) and k7vr\k7vr.log.
  Controls, settings and known issues: see the README on GitHub.

Uninstall
  Delete XINPUT1_3.dll, openvr_api.dll and the k7vr folder from the game folder.
