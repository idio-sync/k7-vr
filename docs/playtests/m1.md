# Playtest: headset stereo, both eyes like the game, HUD panel, controllers (M1–M3)

Setup (the test copy only; your Steam install is untouched):

1. SteamVR running, headset and both controllers on and tracking.
2. `powershell -File C:\Users\Virtual\Git\killer7-vr\tools\profile.ps1 playtest`
3. `powershell -File C:\Users\Virtual\Git\killer7-vr\tools\run.ps1 -Normal`
   (or start `C:\Users\Virtual\killer7-vr-game\Killer7Win.exe`). The language screen shows on
   every boot.
4. Sit facing forward when the game starts; the view recentres on the first frame (and when
   you hold both stick clicks for a second).

Controllers (new; first time on real hardware, so note anything that doesn't respond):

| | right hand | left hand |
|---|---|---|
| trigger | fire | walk (hold) |
| grip | aim mode (hold) | scan (hold) |
| A / X | accept | special |
| B / Y | skip / decline | map |
| stick | aim / menu arrows | up: walk, down: turn around, left/right: choose (menus, junctions) |
| stick click | reload | game menu |

Keyboard still works when the game window has focus: Space = accept / hold to aim, W = walk,
arrows = aim, J = fire, A/D = left/right in Yes/No menus, F12 = quit to title.

Route: Target 00 (Angel): New Game → Normal → aim the dot at Garcian's silhouette and fire →
long cutscene → No to "learn the controls?" → corridor → walk forward → lobby.

What to look at:

- [ ] Sharpness: the game now renders each eye at your headset's recommended 2444×2444
      (was 1920×1440 stretched). The near-vertical lines should be gone. If the frame rate
      can't keep up (reprojection wobble), set `eye_scale=0.8` under `[vr]` in
      `k7vr\k7vr.ini`, or lower SteamVR's refresh rate to 120 or 90 Hz.
- [ ] The opening shot registers now (it didn't in VR before: the game checks hits against a
      copy of its own frame, which is now drawn from its own camera).
- [ ] Menus, title, language screen: on a large flat screen about 3 m in front of you.
- [ ] Cutscenes: in 3D around you; name cards, subtitles and their highlight effects together
      on the panel about 2 m in front, slightly low. Depth looks natural; if the world feels
      too big or small, note which (`unit_m`, default 0.25 m per game unit).
- [ ] Junction icons and the compass on the panel, not glued to your face.
- [ ] Aim mode: Dan's arm and gun are shrunk in place (`gun_scale`, default 0.6); say whether
      they're now a believable size. They still follow the game's aim; controller aiming is M4.
- [ ] Turning and leaning your head: the scene stays put; scenery up to about 75° off the game
      camera, black beyond that is expected.
- [ ] Flat coloured slabs anywhere: note where (`card_mode=skip` under `[vr]` hides them).
- [ ] Smoothness and comfort, especially at camera cuts.

Afterwards: `tools\profile.ps1 test` to put the copy back into unattended-test mode, and send
`C:\Users\Virtual\killer7-vr-game\k7vr\k7vr.log` (it records the controller types and button
codes, the headset's projection and any OpenVR errors).
