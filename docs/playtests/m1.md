# Playtest M1 + M2: headset stereo, both eyes like the game, HUD panel

Setup (the test copy only; your Steam install is untouched):

1. SteamVR running, headset on and tracking (Steam Link to the Frame as usual).
2. `powershell -File C:\Users\Virtual\Git\killer7-vr\tools\profile.ps1 playtest`
3. Start `C:\Users\Virtual\killer7-vr-game\Killer7Win.exe` (the window opens normally, sound on).
   The language screen shows on every boot. Keyboard for now (controllers come in M3):
   Space = accept / hold to aim, W = walk, arrows = aim, J = fire, A/D = left/right in
   Yes/No menus, F12 = quit to title.
4. Sit facing forward when the game starts; the view recentres on the first frame.

Route: Target 00 (Angel): New Game → Normal → shoot Garcian's silhouette (the dot starts on
him; J) → long cutscene → No to "learn the controls?" (D, Space) → corridor → walk forward
(W) → lobby.

What to look at:

- [ ] Menus, title, language screen: on a large flat screen about 3 m in front of you, with
      black around it.
- [ ] Real-time cutscenes: in 3D around you; name cards and subtitles on a smaller panel
      about 2 m in front, slightly low. Depth looks natural, not giant or tiny. If the world
      seems too big or too small, note which; the scale is `unit_m` in `k7vr\k7vr.ini`
      (default 0.25 m per game unit; a smaller value makes the world look bigger).
- [ ] The game's look in both eyes: scanlines, colour, dimming behind name cards.
- [ ] Running sections: compass and reticle on the panel, not glued to your face.
- [ ] Turning and leaning your head: the scene stays put (no swimming). Up to about 75° off
      the game camera there should be scenery; beyond that, black is expected.
- [ ] Flat coloured slabs or a frozen copy of the picture anywhere: note where (screenshot if
      you can). Light/fog cards are clipped to the game camera's view; if they look wrong,
      try `card_mode=skip` under `[vr]` in `k7vr\k7vr.ini`.
- [ ] Camera cuts: you jump with the game camera, nothing lags behind.
- [ ] Aim mode (hold Space): first person with the gun; note how it feels when the game camera
      turns with your aim (controller aiming and a still world come in M4).
- [ ] Smoothness: judder or reprojection artefacts; whether the game runs at normal speed.

Afterwards: `tools\profile.ps1 test` to put the copy back into unattended-test mode, and send
`C:\Users\Virtual\killer7-vr-game\k7vr\k7vr.log` (it records the headset's projection and
any OpenVR errors). If SteamVR isn't running, the log says `vr: VR_Init failed` and the game
simply runs flat.
