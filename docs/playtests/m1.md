# M1 playtest: headset stereo in the running sections

Setup (the test copy only; your Steam install is untouched):

1. SteamVR running, headset on and tracking (Steam Link to the Frame as usual).
2. `powershell -File C:\Users\Virtual\Git\killer7-vr\tools\profile.ps1 playtest`
3. Start `C:\Users\Virtual\killer7-vr-game\Killer7Win.exe` (the window opens normally, sound on).
   The language screen shows on every boot. Keyboard: Space = accept/aim, W = walk,
   arrows = aim, J = fire, A/D = left/right in Yes/No menus, F12 = quit to title.
4. Sit facing forward when the game starts; the view recentres on the first frame.

What to look at (Target 00: Angel; New Game → Normal → shoot Garcian's silhouette → long
cutscene → answer No to "learn the controls?" → corridor → walk forward → lobby):

- [ ] Menus and the language screen appear in the headset (in stereo, HUD glued to the view
      for now; the HUD panel comes in M2).
- [ ] Cutscenes: depth looks natural, not giant or tiny. If the world looks too big or too
      small, note which; the scale is `unit_m` in `k7vr\k7vr.ini` (default 0.25 m per unit;
      smaller value = world looks bigger).
- [ ] Turning and leaning your head: the scene stays put (no swimming), up to about 75° off
      the game camera. Flat blue slabs when looking around are known (M2).
- [ ] Camera cuts: you jump with the game camera, nothing lags behind.
- [ ] Aim mode (hold Space): the view is first person; note how it feels when the game camera
      turns with your aim (controller aiming and the still world come in M4).
- [ ] No post effects (blur/colour grading) in the headset yet; expected until M2.
- [ ] Smoothness: any judder or reprojection artefacts; whether the game runs at normal speed.

Afterwards: `tools\profile.ps1 test` to put the copy back into unattended-test mode, and send
`C:\Users\Virtual\killer7-vr-game\k7vr\k7vr.log` (it records the headset's projection and
any OpenVR errors).

If the game shows no image in the headset or SteamVR isn't running, the log says
`vr: VR_Init failed` and the game simply runs flat.
